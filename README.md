# Skip Safe

**Know exactly how many classes you can skip.**

An attendance risk calculator for BIT Mesra students. Exception-based model — mark only what you skip, not what you attend.

## Features

- **Skips Remaining** — the one number that matters, per subject
- **Today View** — see all classes with color-coded risk (green/amber/red)
- **Dashboard** — all subjects sorted by danger level
- **Subject Detail** — history, stats, class cancellation tracking
- **Offline-first** — works without internet (PWA with service worker)
- **Installable** — add to home screen on any Android phone
- **Zero dependencies** — pure HTML/CSS/JS, no framework, < 50KB

## Install on Phone

1. Open the deployed URL in Chrome
2. Tap ⋮ menu → **Add to Home Screen**
3. Done — opens fullscreen like a native app, works offline

## Tech

- Vanilla HTML + CSS + JS (no build step)
- PWA (manifest.json + service worker)
- localStorage for data persistence
- True black AMOLED-optimized design
